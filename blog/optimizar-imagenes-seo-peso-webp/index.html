Cómo Optimizar Imágenes para SEO: WebP, Peso y Atributo Alt

Por Erik Ladstatter · 12 de Noviembre de 2026 · 7 min de lectura

Respuesta Rápida: ¿Cómo optimizar imágenes para SEO?

Para optimizar imágenes para SEO de manera profesional, debés cumplir cuatro pasos fundamentales: convertir los archivos a formatos modernos como WebP o AVIF para reducir el peso por debajo de 150 KB sin sacrificar nitidez; nombrar el archivo con palabras clave descriptivas separadas por guiones medios (ej: diseno-web-san-juan-profesional.webp); redactar un atributo alt contextual y conciso que describa la escena; y definir explícitamente los atributos width y height en la etiqueta HTML para evitar desplazamientos de diseño acumulado (CLS) en Core Web Vitals.

El Impacto de las Imágenes en el Posicionamiento Web

Las imágenes representan en promedio más del 60% del peso total transferido en una página web. Cuando un sitio web aloja fotos sin comprimir directas de cámara o de bancos de imágenes que pesan entre 3 y 8 MB cada una, el tiempo de renderizado móvil se dispara a más de 6 segundos. Como consecuencia directa, Google penaliza la experiencia de página del sitio y los usuarios abandonan la navegación antes de interactuar.

Comparativa de Formatos de Imagen en 2026

Elegir el formato adecuado para cada tipo de contenido gráfico es la decisión más sencilla y con mayor retorno en rendimiento:

Formato Peso Promedio Transparencia Uso Recomendado
WebP 30 a 120 KB Sí Estándar web universal: fotografías de blog, banners y productos.
AVIF 20 a 90 KB Sí Compresión extrema para navegadores de última generación.
JPEG / JPG 150 a 450 KB No Formato legado; sólo como fallback si no se soporta WebP.
PNG 300 KB a 2 MB Sí Sólo para capturas de interfaz con texto fino que no toleran pérdida.
SVG 2 a 25 KB Sí Logotipos, iconos y vectores sin pérdida de nitidez en zoom.

Cómo Nombrar los Archivos y Escribir el Atributo Alt

Google Imágenes es un canal relevante de atracción de tráfico. Los robots no pueden "ver" una imagen como un ser humano, sino que interpretan dos metadatos esenciales:

  • Nombre del archivo físico: Nunca subas IMG_20261112_WA0045.jpg. Renombrá el archivo antes de subirlo con términos semánticos representativos: consultorio-odontologico-san-juan.webp.
  • Atributo Alt (texto alternativo): Debe describir la imagen con naturalidad para personas con lectores de pantalla y para el algoritmo. Evitá amontonar palabras clave; una frase descriptiva de 6 a 12 palabras es óptima.
  • Lazy Loading nativo: En imágenes por debajo del primer scroll utilizá el atributo loading="lazy" para diferir la carga hasta que el usuario llegue a esa sección. La imagen hero superior nunca debe llevar lazy loading, ya que perjudicaría el tiempo de LCP.

Core Web Vitals y Prevención de Desplazamientos (CLS)

Cuando una imagen se descarga sin dimensiones declaradas, el contenido del texto salta bruscamente hacia abajo una vez cargada la foto. Este comportamiento penaliza el Cumulative Layout Shift (CLS) en Google. Indicando siempre los atributos width="1200" height="675" en la etiqueta, el navegador reserva la caja exacta desde el primer milisegundo. Preguntas Frecuentes sobre Optimización de Imágenes

¿Cuál es el peso máximo recomendado para una imagen en una web? +
La regla estándar de rendimiento web exige que las imágenes principales (heroes o banners) no superen los 150-200 KB, mientras que las imágenes complementarias dentro de artículos o fichas de catálogo deben pesar menos de 80-100 KB para evitar demoras en el LCP.
¿Por qué es conveniente usar el formato WebP en lugar de JPG o PNG? +
El formato WebP desarrollado por Google ofrece compresión con y sin pérdidas entre un 25% y un 35% superior a JPEG y PNG con idéntica calidad visual, reduciendo el consumo de ancho de banda y acelerando drásticamente los tiempos de carga móvil.
¿Cómo redactar un atributo alt correcto para posicionamiento SEO? +
El atributo alt debe describir con naturalidad y precisión lo que muestra la imagen, incorporando la palabra clave o sinónimo de manera contextual sin caer en keyword stuffing (por ejemplo: 'alt="plano de arquitectura moderna de casa unifamiliar en mendoza"').
¿Las dimensiones width y height deben indicarse siempre en la etiqueta img? +
Sí, siempre deben declararse los atributos width y height en el HTML para que el navegador reserve el espacio en pantalla antes de descargar la imagen, evitando saltos visuales bruscos y protegiendo el puntaje de CLS (Cumulative Layout Shift) en Core Web Vitals.
